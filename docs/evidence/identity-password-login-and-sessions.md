# Identity password login and sessions evidence

This map links the [approved specification](../specs/identity-password-login-and-sessions.md#success-criteria) to tests and review evidence. The threat IDs refer to the [Identity threat model](../security/identity-threat-model.md#threats-controls-and-evidence).

| Criterion | Evidence | Threat IDs |
| --- | --- | --- |
| Correct password creates one session and distinct tokens. | [committed login](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L62) shows one session and its subject. [distinct tokens](../../services/identity/internal/app/password_login_service_test.go#L92) appear after commit. [token expiry](../../services/identity/internal/app/session_service_test.go#L54) asserts access, refresh, and session expiry times. [REST response](../../services/identity/internal/adapter/in/http/password_login_handler_test.go#L57) shows the public result. | ID-T02, ID-T09, ID-T11 |
| A repeated login creates a new session without token replay. | [repeat login](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L69) shows two committed sessions and a new refresh token. | ID-T11 |
| Lost signup or claim responses recover through login. | [signup recovery](../../services/identity/internal/adapter/out/postgres/identity_repository_test.go#L542) shows login after a lost response returns the same subject and a new token pair. [claim recovery](../../services/identity/internal/adapter/out/postgres/account_claim_repository_test.go#L168) shows the same result after a claim. | ID-T11 |
| Missing, retired, and wrong-password accounts have one safe failure. | [invalid logins](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L77) give the same error for missing and wrong-password accounts. [retired login](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L111) gives that error too. [timing comparison](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L104) compares missing and wrong-password median times. [REST error](../../services/identity/internal/adapter/in/http/password_login_handler_test.go#L62) shows a safe 401 response. | ID-T01, ID-T02 |
| Both login limits deny before hashing and recover after the window. | [source limit](../../services/identity/internal/adapter/out/postgres/limit_repository_test.go#L177) shows the 60/61 limit and window recovery across two pools. [email limit](../../services/identity/internal/adapter/out/postgres/limit_repository_test.go#L215) shows the 10/11 limit and window recovery. [limit before hashing](../../services/identity/internal/app/password_login_service_test.go#L69) shows denial before account lookup and hashing. | ID-T01, ID-T02, ID-T16 |
| Unverified login succeeds while Workspace denies access. | [unverified login](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go#L45) shows that the account receives a session. [Workspace admission](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go#L185) denies access until verification. | ID-T14 |
| Refresh rotates once and keeps the absolute expiry. | [refresh rotation](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go#L26) shows a new token pair on the same session and the idle and absolute expiry limits. | ID-T11, ID-T12 |
| Idle and absolute expiry deny refresh. | [expiry boundaries](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go#L150) reject refresh at both limits. | ID-T11, ID-T19 |
| Replay and concurrent refresh revoke one device. | [replay handling](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go#L77) and [concurrent refresh](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go#L94) revoke the affected session while another device stays active. | ID-T11, ID-T12 |
| A lost refresh response cannot replay its old token. | [old-token replay](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go#L77) fails after rotation commits. | ID-T11, ID-T12 |
| Current-device logout commits before later checks. | [current logout](../../services/identity/internal/adapter/out/postgres/current_session_logout_repository_test.go#L69) rejects the logged-out session while another device stays active. [live revocation](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go#L209) denies a locally valid token. | ID-T09, ID-T13 |
| All-device logout revokes old sessions and permits later login. | [all-device logout](../../services/identity/internal/adapter/out/postgres/all_session_logout_repository_test.go#L27) shows old sessions are revoked and a later login succeeds. Its subtests cover both commit orders and rollback. | ID-T09, ID-T13 |
| Identity outage denies Workspace admission. | [Identity outage](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go#L203) shows Workspace denies access when the live mTLS session call finds an expired or revoked session or Identity is unavailable. | ID-T14, ID-T16 |
| Verification state changes on the next live check. | [live verification](../../services/identity/internal/bootstrap/session_rpc_integration_test.go#L140) shows current state and rejects wrong subjects, revoked or expired sessions, and retired accounts. [client certificates](../../services/identity/internal/bootstrap/session_tls_test.go#L197) reject missing, expired, untrusted, and wrong-service certificates. | ID-T14 |
| Signing keys overlap and retire safely. | [key overlap](../../services/identity/internal/adapter/out/token/token_verifier_test.go#L79) shows both key IDs work during overlap. [invalid claims](../../services/identity/internal/adapter/out/token/token_verifier_test.go#L112) fail verification. [retirement script](../../scripts/retire-identity-signing-key-local.test.sh) shows the local guard. | ID-T10, ID-T19 |
| Contract, database, abuse, concurrency, and cross-service checks pass. | [public login input](../../services/identity/internal/adapter/in/http/password_login_handler_test.go#L41) covers the REST request. [hash capacity](../../services/identity/internal/app/password_login_service_test.go#L185) covers denial when all hash slots are full. [safe telemetry](../../services/identity/internal/bootstrap/server_test.go#L71) covers credential-free logs. [PR #189 checks](https://github.com/vasapolrittideah/flowspace-api/pull/189/checks) run the full suites. | ID-T15, ID-T16, ID-T17, ID-T20 |

The private [session RPC](../../services/identity/internal/bootstrap/session_rpc_test.go#L69) shows caller authentication, failure codes, bounded metric labels, and logs without subject or session IDs. [Canceled calls](../../services/identity/internal/adapter/in/grpc/session_check_handler_test.go#L48) return the expected code. The [logout response](../../services/identity/internal/adapter/in/http/logout_current_session_handler_test.go#L93) has a no-store header. [Refresh errors](../../services/identity/internal/adapter/in/http/refresh_session_handler_test.go#L101) do not expose the token.
