# Architecture decision records

These records capture accepted, durable architectural directions. Each record groups decisions that share one architectural concern; replaceable tools and libraries belong in [technology choices](../technology-choices.md), not separate ADRs.

Unresolved proposals stay in the [architecture overview](../architecture-overview.md). Create or revise an ADR only after a proposal is accepted.
