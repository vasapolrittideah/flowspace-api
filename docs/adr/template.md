## Context

What forces are at play? Constraints (hardware, budget, team size), the problem
being solved, and anything that would surprise a reader six months from now.
State facts, not the decision. If a constraint is self-imposed, say so.

## Decision

We will `do X`.

One paragraph, present tense, unambiguous. A reader must be able to tell whether
a given pull request violates this ADR.
