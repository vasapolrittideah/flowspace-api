# Identity password login and sessions evidence

This record maps the [approved specification](../specs/identity-password-login-and-sessions.md#success-criteria) to tests and review checks. The numbered rows follow the success criteria in order. The threat IDs refer to the [Identity threat model](../security/identity-threat-model.md#threats-controls-and-evidence).

| Criterion | Evidence | Threat IDs |
| --- | --- | --- |
| 1. Correct password creates one session and distinct tokens. | [PostgreSQL login test](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go), [REST and RPC tests](../../services/identity/internal/adapter/in/http/password_login_handler_test.go) | ID-T02, ID-T09, ID-T11 |
| 2. A repeated login creates a new session without token replay. | [PostgreSQL login test](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go) checks two committed sessions. | ID-T11 |
| 3. Lost signup or claim responses recover through login. | [Signup session test](../../services/identity/internal/adapter/out/postgres/identity_repository_test.go), [claim test](../../services/identity/internal/adapter/out/postgres/account_claim_repository_test.go), and [PostgreSQL login test](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go) cover the shared subject and a new token pair. | ID-T11 |
| 4. Missing, retired, and wrong-password accounts have one safe failure. | [PostgreSQL login test](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go) compares errors and median times for missing and wrong-password accounts; [REST test](../../services/identity/internal/adapter/in/http/password_login_handler_test.go) checks status and safe bodies. | ID-T01, ID-T02 |
| 5. Both login limits deny before hashing and recover after the window. | [Shared PostgreSQL limit tests](../../services/identity/internal/adapter/out/postgres/limit_repository_test.go) cover 60/61 and 10/11 attempts across two pools, rejected counts, and window recovery; [service test](../../services/identity/internal/app/password_login_service_test.go) checks the order before hashing. | ID-T01, ID-T02, ID-T16 |
| 6. Unverified login succeeds while Workspace denies access. | [PostgreSQL login test](../../services/identity/internal/adapter/out/postgres/password_login_repository_test.go) and [Workspace admission integration test](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go). | ID-T14 |
| 7. Refresh rotates once and keeps the absolute expiry. | [PostgreSQL refresh test](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go) checks the token pair, same session, idle expiry, and absolute cap. | ID-T11, ID-T12 |
| 8. Idle and absolute expiry deny refresh. | [PostgreSQL refresh test](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go) checks both expiry boundaries. | ID-T11, ID-T19 |
| 9. Replay and concurrent refresh revoke one device. | [PostgreSQL refresh test](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go) checks replay, concurrent calls, current-token rejection, and another device. | ID-T11, ID-T12 |
| 10. A lost refresh response cannot replay its old token. | The same [PostgreSQL refresh test](../../services/identity/internal/adapter/out/postgres/refresh_session_repository_test.go) reuses the old token after a committed rotation. | ID-T11, ID-T12 |
| 11. Current-device logout commits before later checks. | [PostgreSQL current logout test](../../services/identity/internal/adapter/out/postgres/current_session_logout_repository_test.go) and [Workspace admission integration test](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go). | ID-T09, ID-T13 |
| 12. All-device logout revokes old sessions and permits later login. | [PostgreSQL all-session logout test](../../services/identity/internal/adapter/out/postgres/all_session_logout_repository_test.go) covers both commit orders and transaction rollback. | ID-T09, ID-T13 |
| 13. Identity outage denies Workspace admission. | [Workspace admission integration test](../../services/workspace/internal/bootstrap/workspace_admission_integration_test.go) checks local token validation, live mTLS check, expiry, revocation, and unavailable Identity. | ID-T14, ID-T16 |
| 14. Verification state changes on the next live check. | [Private listener integration test](../../services/identity/internal/bootstrap/session_rpc_integration_test.go) checks the current state, wrong subject, revocation, expiry, retired account, public-route isolation, and current verification state. [TLS tests](../../services/identity/internal/bootstrap/session_tls_test.go) reject missing, expired, untrusted, and wrong-service certificates. | ID-T14 |
| 15. Signing keys overlap and retire safely. | [Token verifier tests](../../services/identity/internal/adapter/out/token/token_verifier_test.go) check invalid claims and both key IDs; [local retirement test](../../scripts/retire-identity-signing-key-local.test.sh) checks the rotation guard. | ID-T10, ID-T19 |
| 16. Contract, database, abuse, concurrency, and cross-service checks pass. | [Public input tests](../../services/identity/internal/adapter/in/http/password_login_handler_test.go), [hash-capacity test](../../services/identity/internal/app/password_login_service_test.go), [telemetry tests](../../services/identity/internal/bootstrap/server_test.go), and the verification commands below. | ID-T15, ID-T16, ID-T17, ID-T20 |

The private [RPC test](../../services/identity/internal/bootstrap/session_rpc_test.go) checks caller authentication, failure codes, bounded metric labels, and logs without subject or session IDs. The [handler test](../../services/identity/internal/adapter/in/grpc/session_check_handler_test.go) checks canceled calls. The [REST logout tests](../../services/identity/internal/adapter/in/http/logout_current_session_handler_test.go) and [refresh tests](../../services/identity/internal/adapter/in/http/refresh_session_handler_test.go) check safe public errors and security headers.
